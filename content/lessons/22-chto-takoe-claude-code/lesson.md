# Что такое Claude Code

Блок 4 – **по желанию**. Курс засчитан и без него: всё, что нужно для работы и личных дел, вы уже умеете. Этот блок для тех, кому интересно пойти дальше – получить от Claude не документ, а небольшую работающую вещь: страницу в интернете, программу, которая сама сводит таблицы или переименовывает файлы.

Что изменилось по сравнению с блоком 3: в Cowork Claude выполнял задачу и сдавал результат, а в Claude Code он работает прямо в папке на вашем компьютере – создаёт и правит файлы, запускает программы, – и каждое изменение вы видите и можете отклонить.

Программировать для этого не нужно. Вы описываете, что хотите получить, как в уроке 2, а Claude пишет код. Ваша работа – поставить задачу, следить, что он делает, и проверить результат.

## Чем Claude Code отличается от Cowork

Оба работают в одном приложении Claude для компьютера, на одном тарифе и из одного лимита. Разница – в том, с чем они работают.

| | Cowork (блок 3) | Claude Code |
|---|---|---|
| Для чего | Работа с документами, почтой, сайтами: сводка, отчёт, таблица | Небольшие программы, страницы, обработка файлов в папке |
| Где идёт работа | В облаке; папки и браузер – через приложение | В выбранной папке на вашем компьютере |
| Что вы видите | Ход задачи и готовый результат | Каждое изменение файла построчно, до и после |
| Результат | Документ, таблица, презентация | Файлы в папке: страница, программа, данные |

Простое правило: если результат – документ, который вы прочитаете или отправите, это Cowork. Если результат – вещь, которой будете пользоваться снова и снова (страница, программа на каждый месяц), это Claude Code.

## Где он находится

Claude Code встроен в приложение Claude для компьютера, на вкладке **Code** в верхней части боковой панели. Если вкладки показаны только значками, наведите на них мышь – появятся названия. Терминал (чёрное окно с командами) не нужен: в приложении всё делается кнопками и обычным текстом.

Claude Code входит в Pro. На бесплатном тарифе при нажатии на **Code** приложение предложит перейти на платный.

## Что нужно на Windows

1. **Windows 10 или новее.** Проверить: **Пуск → Параметры → Система → О системе**.
2. **Приложение Claude для компьютера.** Оно у вас уже стоит с блока 2. Скачать заново можно на claude.ai/download. На странице загрузки есть отдельный вариант для процессоров ARM64; какой у вас процессор, видно там же, в **О системе → Тип системы**. У большинства ноутбуков – x64.
3. **Свежая версия приложения.** **Help → Check for Updates…** в меню приложения. Старые версии на Windows требовали Git перед любой работой в **Code**; в нынешних это не нужно.
4. **Git for Windows – не обязательно, но полезно.** Это бесплатный набор инструментов для работы с файлами. Если он установлен, Claude Code пользуется им для команд; если нет – обходится встроенной в Windows программой PowerShell. Ставить его стоит, если приложение покажет сообщение «Git is required» или если Claude сам об этом попросит. Скачивайте только с официального сайта git-scm.com/downloads/win, при установке оставляйте настройки по умолчанию.

Права администратора, Node.js и отдельная установка Claude Code для вкладки **Code** не нужны – всё уже внутри приложения.

## Папка проекта

Claude Code всегда работает в одной папке – она называется папкой проекта. В ней Claude читает и создаёт файлы. За её пределы он без вашего разрешения не выходит.

Правила для папки:

- **Отдельная папка под каждую задачу.** Например, `C:\Users\Айгуль\Documents\Claude\калькулятор-поездки`. Не открывайте весь диск C или всю папку «Документы»: Claude увидит всё, что там лежит.
- **Только то, что нужно для задачи.** Если задача – свести три выгрузки, положите в папку копии этих трёх файлов, а не оригиналы.
- **Без паролей и личных документов.** Сканы паспорта, файлы с паролями, банковские выписки в папку проекта не кладите.

## Как начать сеанс

Сеанс – это разговор с Claude о файлах в одной папке. Начинается он так:

1. Откройте вкладку **Code**.
2. Под полем ввода найдите ряд кнопок. Первая – где работать: выберите верхний пункт в группе **Local** («на этом компьютере»).
3. Рядом – выбор папки: **Open folder…**, затем укажите папку проекта.
4. Проверьте режим разрешений в том же ряду: для начала – **Manual**. В нём Claude спрашивает перед каждой правкой файла и каждой командой. Остальные режимы разберём в уроке 23.
5. Напишите задачу и нажмите Enter.

Кроме **Local** в списке есть **Cloud** – работа на серверах Anthropic. Она удобна программистам, которые держат проекты на GitHub; в курсе мы работаем с папками на своём компьютере.

Если у вас выбор папки и места работы стоит **над** полем ввода, а не под ним, – у вас старое оформление приложения. Обновите его, как в пункте 3 выше.

## Что происходит, когда вы дали задачу

Claude сначала осматривает папку, потом говорит, что собирается сделать, и начинает. В режиме **Manual** перед каждой правкой вы видите, что именно изменится: красным – что уйдёт, зелёным – что появится. Можно одобрить или отклонить.

Остановить Claude можно в любой момент кнопкой остановки. А можно просто написать поправку и нажать Enter – Claude учтёт её, не бросая работу.

Если результат – страница, Claude может показать её прямо в приложении, в панели **Browser** (открывается кнопкой **Browser** вверху или **Ctrl+Shift+B**). Файл со страницей можно открыть и двойным щелчком в Проводнике – он откроется в обычном браузере.

## Как ставить задачу

Всё, что вы знаете с урока 2, работает и здесь. Добавляются три вещи:

- **Опишите результат, а не код.** «Страница, где я ввожу расстояние, расход и цену бензина, а она показывает стоимость поездки» – хорошо. Писать, на каком языке программирования делать, не нужно.
- **Скажите, кто будет пользоваться.** «Пользоваться буду я сам, на ноутбуке» или «откроют гости с телефона» – от этого зависит, как Claude сделает вещь.
- **Попросите объяснить.** «В конце объясни простыми словами, какие файлы ты создал и как этим пользоваться». Код читать не обязательно, а понимать, что лежит в папке, – нужно.

Пример первой задачи:

> В этой папке сделай страницу-калькулятор стоимости поездки на машине. Я ввожу расстояние в километрах, расход литров на 100 км и цену литра в тенге, страница показывает стоимость в одну сторону и туда-обратно. Всё в одном файле, на русском, крупные поля, чтобы было удобно и с телефона. Потом открой её, проверь сам на примере: 450 км, 8 литров, 300 тенге. В конце объясни, какие файлы создал.

## Лимиты

Claude Code на Pro расходует тот же лимит, что и чат с Cowork: есть лимит на пять часов и недельный лимит. Работа над кодом расходует его быстрее обычного разговора, потому что Claude много читает и проверяет. Небольшие задачи этого блока в лимит укладываются; если увидите предупреждение о лимите – сделайте перерыв, работа в папке не пропадёт. Подробнее о лимитах – в уроке 23.

## Итог урока

- Блок 4 – по желанию. Claude Code делает вещи, которыми пользуются: страницы, программы, обработку файлов.
- Он на вкладке **Code** приложения Claude для компьютера; терминал не нужен, Pro достаточно.
- На Windows нужна Windows 10 или новее и свежая версия приложения. Git for Windows – по желанию или по просьбе приложения, только с git-scm.com.
- Работайте в отдельной папке под задачу, без личных документов; для начала – режим **Manual**.
- Ставьте задачу как в уроке 2: результат, кто пользуется, и попросите объяснить, что сделано.
